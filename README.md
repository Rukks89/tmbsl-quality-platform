# TMBSL Manufacturing Quality Intelligence

PDI defect-to-origin traceability platform for TMBSL bus manufacturing. It links a defect found at Pre-Delivery Inspection to candidate shops, stations and operations from the preloaded `Shop-Station-Activity.xlsx` workbook, while keeping "detected at", "potential origin" and "confirmed origin" separate.

## Tech
TanStack Start (React 19, Vite 8), Tailwind CSS 4, shadcn/ui, TypeScript, deployed on Netlify. Master data is generated by a stdlib-only Python script.

## Run locally
```bash
pnpm install
netlify dev            # or: pnpm dev
python3 -I scripts/ingest_workbook.py   # regenerate master data after editing the workbook
```
